# 🌱 FarmCast
### Smart Weather Monitoring for Safer Harvests

**FarmCast** is a web-based agricultural weather monitoring platform designed to help farmers stay informed about local weather conditions and make better decisions to protect their crops. By providing accessible weather forecasts and farming-related advisories, the project aims to support smarter farm management and promote agricultural awareness through technology.

## 📖 About the Project

Weather conditions play an important role in agriculture. Heavy rainfall, strong winds, extreme temperatures, and dry periods can affect crop growth, irrigation, and other farming activities.

FarmCast aims to make weather information easier for farmers to understand by presenting essential weather data in a simple, accessible, and user-friendly interface. The platform will use a free weather API to retrieve weather information and provide general recommendations based on forecast conditions.

## 🎯 Objectives

- Provide current weather information for selected locations.
- Display hourly and daily weather forecasts.
- Help farmers monitor rainfall, temperature, humidity, and wind conditions.
- Present general weather-based advisories to support crop protection.
- Promote the use of information technology in agriculture.
- Develop a responsive website accessible on desktop and mobile devices.

## ✨ Key Features

- **Current Weather Monitoring** — View temperature, humidity, wind speed, rainfall, and current weather conditions.
- **Location Search** — Search for a city or municipality to view its weather information.
- **Weather Forecasts** — Check upcoming weather conditions to help plan farming activities.
- **Farm Weather Advisories** — Receive general precautions based on forecast conditions, such as expected heavy rainfall or strong winds.
- **Crop Protection Tips** — Access practical suggestions for monitoring and protecting crops.
- **Responsive Design** — Use the website on desktop computers, tablets, and smartphones.

*Note: Features may be updated as development progresses.*

## 🌦️ Weather Data Source

FarmCast uses the [Open-Meteo Weather API](https://open-meteo.com/en/docs) to retrieve weather information.

Open-Meteo provides weather forecast data without requiring an API key for its free, non-commercial service. Please refer to its official documentation and terms for usage limits and attribution requirements.

Weather data is intended for informational purposes and should not replace official weather warnings or professional agricultural advice.

## 🚀 Getting Started

### Prerequisites

You will need:
- A modern web browser, such as Google Chrome or Microsoft Edge.
- A code editor, such as Visual Studio Code.
- An internet connection to retrieve weather data from the API.

### Installation

**1. Clone the repository**

```bash
git clone <GITHUB_REPOSITORY_URL>
```

**2. Open the project folder**

```bash
cd FarmCast
```

**3. Open the website**

Open `index.html` in your browser. Alternatively, use the Live Server extension in Visual Studio Code to run the website locally.

**4. Start exploring**

Once the weather API integration is implemented, select a location to view its weather information and available forecasts.

## 🎓 Project Purpose

This project demonstrates how web development and publicly available weather data can be applied to a real-world agricultural concern. FarmCast aims to make weather information more accessible to farmers and encourage informed decisions that may help reduce weather-related risks to crops.

## ⚠️ Disclaimer

FarmCast is an educational project and is not an official weather forecasting or emergency alert service. Weather-based advisories are general suggestions, not guarantees of crop safety. Users should consult official weather bulletins from [PAGASA](https://www.pagasa.dost.gov.ph/) and follow relevant local agricultural guidance when making important farming decisions.
